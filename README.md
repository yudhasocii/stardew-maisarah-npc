\# Stardew Maisarah NPC Mod



A custom mod pack for \*\*Stardew Valley\*\* featuring a custom NPC named \*\*Maisarah\*\* along with a dedicated Service Menu.



\## 📁 Mod Components

This repository contains two main components that work together:

\*   \*\*`\[CP] Maisarah Custom NPC`\*\*: The Content Patcher component containing the character sprites, portraits, maps (`ShikoSpouseRoom.tmx`), schedules, and dialogue configurations.

\*   \*\*`MaisarahServiceMenu`\*\*: The SMAPI C# source code framework that handles the interactive service menu mechanics in the game.



\## 🛠️ Requirements

To run this mod in your game, you will need:

\*   \[SMAPI - Stardew Modding API](https://smapi.io)

\*   \[Content Patcher](https://nexusmods.com)



\## 💻 Installation

1\. Download the compiled release zip file.

2\. Extract the contents.

3\. Copy both the `\[CP] Maisarah Custom NPC` and `MaisarahServiceMenu` folders.

4\. Paste them into your Stardew Valley `Mods` directory (`...\\Stardew Valley\\Mods`).

5\. Run the game via SMAPI.
